# 第1段階のゲームルール

- 1対1
- 1試合60秒
- 最大HP 5、1発1ダメージ
- 移動速度 150 px/s
- 弾速 340 px/s
- 射撃間隔 0.24秒
- 装弾数6発、リロード1秒
- 射撃時に照準と反対方向へ5px反動
- 被弾後0.18秒、リスポーン後1秒の無敵時間
- Spaceで0.13秒ダッシュ、クールダウン1.1秒
- ダッシュ中は射撃不可、無敵時間なし
- 撃破されたプレイヤーは2秒後に復活
- 撃破数が多いプレイヤーが勝利
- 同点時は残りHPで判定
- 終了画面を5秒表示して次の試合を開始

マップは640×360。外周と中央上下の障害物に衝突判定がある。
アイテム、中立敵、ラウンド制は今後の段階で追加する。
