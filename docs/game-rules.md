# ゲームルール

- 人間とCPUを合わせて2〜4人
- 最初に入室した人間がルームホスト
- ホストがCPU追加、ルール変更、試合開始を行う
- ホスト1人で開始した場合は対戦相手のCPUを1体自動追加する
- 人間が全員退出した場合は残ったCPUを削除し、空のルームへ戻す
- 1試合120秒のポイントマッチ
- 試合開始前に3秒のカウントダウン
- 最大HP 5、1発1ダメージ
- 移動速度 150 px/s
- 弾速 340 px/s
- 射撃間隔 0.24秒
- 装弾数6発、リロード1秒
- 射撃時に照準と反対方向へ5px反動
- 被弾後0.18秒、リスポーン後1秒の無敵時間
- Shiftで0.13秒ダッシュ、クールダウン1.1秒
- ダッシュ中は射撃不可、無敵時間なし
- 撃破されたプレイヤーは2秒後に復活
- 相手を撃破すると100ポイント獲得
- 自分が死亡すると25ポイント減少（得点はマイナスになり得る）
- アリーナに5秒間隔でエナジーセルまたはスロットアイテムが出現
- エナジーセルは触れた瞬間に20ポイント獲得
- スロットアイテムは1個だけ保持でき、Spaceで使用する
- ダッシュブーツはクールダウンを無視するダッシュを5回使用可能
- ラロキンポッポスは得点首位の相手へ四方向から10体突撃し、1体1ダメージ
- バーサークは3秒間、攻撃力・弾速・射程が上がる代わりに移動速度が半減
- シールドは発動後2ダメージ分を防ぐ
- ゴーストはアイテムを持つ最寄りの相手からスロットアイテムを奪う
- 得点アイテムはアリーナに最大3個まで存在
- タイムアップ時にポイントが高いプレイヤーが勝利
- タイムアップ時に同点なら引き分け
- 試合終了画面を6秒表示して次の試合を開始
- ロビー退出は即座に参加者一覧と人数へ反映
- 試合中の切断時は試合を一時停止し、15秒間は同じプレイヤーとして再接続可能
- 15秒以内に戻らず残りが1人になった場合は、そのプレイヤーの勝利
- 3人以上の試合で途中離脱した場合は、2人以上残っていれば試合を継続する

マップは640×360。外周と中央上下の障害物に衝突判定がある。
リスポーン地点は6候補から、相手と飛来中の弾から離れた地点を選択する。
得点、アイテム生成、取得判定、勝敗はすべてサーバーが決定する。
