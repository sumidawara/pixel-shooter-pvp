# ゲームルール

- 1対1
- 1試合120秒のポイントマッチ
- 試合開始前に3秒のカウントダウン
- 最大HP 5、1発1ダメージ
- 移動速度 150 px/s
- 弾速 340 px/s
- 射撃間隔 0.24秒
- 装弾数6発、リロード1秒
- 射撃時に照準と反対方向へ5px反動
- 被弾後0.18秒、リスポーン後1秒の無敵時間
- Spaceで0.13秒ダッシュ、クールダウン1.1秒
- ダッシュ中は射撃不可、無敵時間なし
- 撃破されたプレイヤーは2秒後に復活
- 相手を撃破すると100ポイント獲得
- 自分が死亡すると25ポイント減少（得点はマイナスになり得る）
- アリーナに5秒間隔で出現するアイテムを取ると20ポイント獲得
- 得点アイテムはアリーナに最大3個まで存在
- タイムアップ時にポイントが高いプレイヤーが勝利
- タイムアップ時に同点なら引き分け
- 試合終了画面を6秒表示して次の試合を開始
- 切断時は試合を一時停止し、15秒間は同じプレイヤーとして再接続可能
- 15秒以内に戻らない場合は途中離脱として相手の勝利

マップは640×360。外周と中央上下の障害物に衝突判定がある。
リスポーン地点は6候補から、相手と飛来中の弾から離れた地点を選択する。
得点、アイテム生成、取得判定、勝敗はすべてサーバーが決定する。
