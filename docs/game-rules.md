# ゲームルール

- 人間とCPUを合わせて2〜4人
- 最初に入室した人間がルームホスト
- ホストがCPU追加、ルール変更、試合開始を行う
- ホスト1人で開始した場合は対戦相手のCPUを1体自動追加する
- 人間が全員退出した場合は残ったCPUを削除し、空のルームへ戻す
- 1試合120秒のポイントマッチ
- 試合開始前に3秒のカウントダウン
- 最大HP 5、1発1ダメージ
- 移動速度 150 px/s
- 弾速 340 px/s
- 射撃間隔 0.24秒
- 装弾数6発、リロード1秒
- 射撃時に照準と反対方向へ5px反動
- 被弾後0.18秒、リスポーン後1秒の無敵時間
- Shiftで0.13秒ダッシュ、クールダウン1.1秒
- ダッシュ中は射撃不可、無敵時間なし
- 撃破されたプレイヤーは2秒後に復活
- 相手を撃破すると100ポイント獲得
- 自分が死亡すると25ポイント減少（得点はマイナスになり得る）
- アリーナに5秒間隔でエナジーセルまたはスロットアイテムが出現
- エナジーセルは触れた瞬間に20ポイント獲得
- スロットアイテムは1個だけ保持でき、Spaceで使用する
- ダッシュブーツはクールダウンを無視するダッシュを5回使用可能
- ラロキンポッポスは得点首位の相手へ四方向から10体突撃し、1体1ダメージ
- バーサークは3秒間、攻撃力・弾速・射程が上がる代わりに移動速度が半減
- シールドは発動後2ダメージ分を防ぐ
- ゴーストはアイテムを持つ最寄りの相手からスロットアイテムを奪う
- 得点アイテムはアリーナに最大3個まで存在
- タイムアップ時にポイントが高いプレイヤーが勝利
- タイムアップ時に同点なら引き分け
- 試合終了画面を6秒表示して次の試合を開始
- ロビー退出は即座に参加者一覧と人数へ反映
- 試合中の切断時は試合を一時停止し、15秒間は同じプレイヤーとして再接続可能
- 15秒以内に戻らず残りが1人になった場合は、そのプレイヤーの勝利
- 3人以上の試合で途中離脱した場合は、2人以上残っていれば試合を継続する

## 自動生成マップ（RANDOM）

ロビーのマップ一覧で `RANDOM (NEW EACH MATCH)` を選ぶと、地形を自動生成する。
選んだ時点で1枚作られ、**試合を開始するたびに作り直す**。同じ地形を繰り返したい
場合は手書きのマップを選ぶ。

「遊べる形」を次の5つに分解し、すべて生成の構造で保証している。
種400通りで毎回検査している（`backend/game-core/src/arena/generator.rs`）。

- **点対称** — どのスポーン地点から見ても地形の有利不利が同じ
- **全部つながっている** — 行けない床や閉じ込めを作らない
- **遮蔽がある** — 内側の壁は10〜22%。空箱でも迷路でもない
- **スポーンが離れている** — 開始直後に撃ち合いにならない
- **アイテムの置き場所が6箇所** — 練習場が全種類を並べてもそのまま使える

壁の塊どうしには必ず1マス以上の隙間を空ける。くっつけて置けるようにすると
重なりが連鎖して一枚の大きな壁になり、遮蔽ではなく行き止まりだらけの地形になる。
外周の壁のすぐ内側は必ず通路として残すので、4隅のスポーンは常に1本の輪でつながる。

大きさは手書きのマップと同じ20×11タイル。地形は種(seed)から決まり、同じ種なら
必ず同じマップになる。実際に使われた種はサーバーのログに残る。

## サンドボックス（練習場）

アイテムの効果や武器の威力を1人で試すための設定。CREATE ROOM の
MATCH PARAMETERS にある `SANDBOX` を有効にして START すると、
通常の試合ではなく練習場が始まる。

対戦と違うのは次の4点だけで、それ以外は通常の試合とまったく同じ計算を通す。
練習場だけ挙動が違うと、確かめた結果が本番で当てにならなくなる。

- 空きスロットが `DUMMY-n` で埋まる。動かず、撃たず、こちらを狙いもしない
- 全6種類のアイテムが常に置かれ、取られると1秒で戻る
- 試合が時間で終わらない。抜けるときはルームを出る
- ダミーを倒しても得点は動かない（勝敗を決める場ではないため）

ダミーは「動かない的」ではなく普通のプレイヤーとして置いている。
ゴーストは *アイテムを持つ相手* からしか奪えず、ラロキンポッポスは
*得点首位のプレイヤー* を狙うため、別種の的にするとこの2つだけ試せなくなる。
ゴーストを試せるよう、ダミーには常にスロットアイテムを持たせてある。

人数上限は通常の試合と同じ4人なので、ダミーは最大3体。
`ADD CPU` で撃ち返してくるCPUを混ぜることもでき、その場合はダミーが減る。
画面上では、CPUは名前のうしろに `*`、ダミーは `-` が付く。

マップは640×360。外周と中央上下の障害物に衝突判定がある。
リスポーン地点は6候補から、相手と飛来中の弾から離れた地点を選択する。
得点、アイテム生成、取得判定、勝敗はすべてサーバーが決定する。
