# ゲームルール

- 1対1
- 1ラウンド60秒、3ラウンド先取
- ラウンド開始前に3秒のカウントダウン
- ラウンド間に3秒のインターバル
- 最大HP 5、1発1ダメージ
- 移動速度 150 px/s
- 弾速 340 px/s
- 射撃間隔 0.24秒
- 装弾数6発、リロード1秒
- 射撃時に照準と反対方向へ5px反動
- 被弾後0.18秒、リスポーン後1秒の無敵時間
- Spaceで0.13秒ダッシュ、クールダウン1.1秒
- ダッシュ中は射撃不可、無敵時間なし
- 撃破されたプレイヤーは2秒後に復活
- 撃破数が多いプレイヤーが勝利
- 時間切れで撃破数が同じ場合は30秒の延長戦
- 延長戦は先に相手を撃破したプレイヤーが勝利
- 延長時間切れ時は残りHPで判定し、HPも同じなら10秒ずつ継続
- 試合終了画面を6秒表示して次の試合を開始
- 切断時は試合を一時停止し、15秒間は同じプレイヤーとして再接続可能
- 15秒以内に戻らない場合は途中離脱として相手の勝利

マップは640×360。外周と中央上下の障害物に衝突判定がある。
リスポーン地点は6候補から、相手と飛来中の弾から離れた地点を選択する。
アイテムと中立敵は今後の段階で追加する。
